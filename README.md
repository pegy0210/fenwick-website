# Fenwick Website

Fenwick 個人品牌網站，內容包括繁體／簡體切換、4大內容範疇、YouTube 影片預留位置、免費規劃清單及 WhatsApp 導流表單。

## 本地執行

```bash
npm install
npm run dev
```

## 建置

```bash
npm run build
npm run preview
```

## 目前設定

- 預設語言：繁體中文
- WhatsApp：85267265788
- 表單提交：開啟 WhatsApp，並自動帶入訪客填寫的內容
- 影片：暫時使用預留位置，日後可換成 YouTube iframe 或縮圖
